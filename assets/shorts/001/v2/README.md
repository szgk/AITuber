# 顔を隠す仕草と作画を合わせた背景

[ADR 0016](../../../../docs/adr/0016-hair-gesture-and-matched-background.md)による修正版。組み込みのimage_genで生成し、このフォルダーへ保存した。[生成プロンプト全文](prompts.json)を併記する。

- `hair-raise.png`: 立ったまま手を前髪へ伸ばす。
- `hair-hide.png`: 手と前髪で目元・鼻・口が隠れる。
- `hair-tuck.png`: 手を耳元へ移して髪をよける。
- `room.png`: 人物を作画の参照として生成した、太い黒線と簡単な塗りの室内。

人物3点の参照・編集元は[既存の立ち姿](../standing.png)。背景にも同じ画像を作画参照として使った。人物は実透過PNG、背景は不透明PNG。旧お辞儀素材は現行動画で使わない。

現行の[台本](../../../../projects/short-001/storyboard.json)の第4場面は、立ち姿→手を上げる→顔を隠す→髪をよける→立ち姿の順に切り替える。上体と足元は固定する。画像生成だけで連続動画になったものではなく、専用ポーズを時系列で合成する2D演出。
