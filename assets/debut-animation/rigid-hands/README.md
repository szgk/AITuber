# 剛体回転用の手パーツ

原画の手の肌と黒い輪郭を抽出したPNGを回転・並進する。手や指の中にメッシュ変形は使わない。回転中心と振幅はrigs.jsonに保存する。

- `03-hand.png` / `15-hand.png`: 元絵の手を保持したアルファ付きレイヤー。
- `03-plate.png` / `15-plate.png`: 元の手が重複して残らないための補完下絵。
- `03-clean-generated.png` / `15-clean-generated.png`: 組み込みimagegenによる補完生成の元出力。下絵全体を置き換えず、手の後ろに必要な範囲だけを利用する。

生成指示: 03は「挨拶している手の指・掌・手首の肌だけを除去し、後ろの灰色背景と黒髪を補完する。袖口と紺の袖、頭頂部、前景パネル、構図、線と塗りは保持する」。15も「挨拶の手だけを除去し、後ろの黒髪・頬の輪郭・ジャケットを補完する。袖口と腕、笑顔、髪型、服、構図、線と塗りは保持する」。別の手や新しいポーズは追加しない。

抽出処理は `tools/prepare_hand_parts.py`。最終動画の手首・指・旧手の残像は実MP4から確認する。
