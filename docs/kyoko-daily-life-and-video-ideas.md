# 望月京子の日常設定と動画企画

ショートでは一つのこだわりや小さな失敗を、ロングではその前後にある気持ちと変化を描く。中心に置くのは「人と話すのは苦手だけれど、今日あったことを誰かに聞いてほしい32歳の京子」。視聴後に、次の日の京子も少し気になる日常シリーズを目指す。

以下の追加設定とエピソードは初期案。既存プロフィールを土台にし、制作しながら採用・修正する。実行用の人格設定や学習データにはまだ反映しない。

設定の採用や変更は [ADR 0002](adr/0002-record-settings-and-decisions.md) に従ってADRに記録する。

## 採用済みの背景設定（2026-10-24追加）

[ADR 0026](adr/0026-kyoko-awakening-in-pc.md)を正とする。元OLの京子はPC内の見知らぬ部屋で目覚め、外はまだ真っ暗。変化の経緯と直前の記憶はないが、AITuberになったことはわかる。画面の中からウェブやPC画面が見え、今行けるのは最初の部屋・PC画面・ネットの中。ネットはまだ怖くてよくわからない。元々好きだったYouTubeと、以前から使っていたXで情報発信し、みんなと交流しながら元に戻る方法を探す。この採用済み設定はプロフィールにも反映した。

以下の商店街・通販・朝昼の暮らしなどは未採用案であり、現在の行動範囲や世界の仕組みとして確定していない。今後できることを段階的に実装する方針は制作側だけの情報で、本人は知らない。

## 既存設定

出典は [キャラクタープロフィール](../data/character_profile.json)。

- 32歳の女性。引っ込み思案で内向的、優しく遠慮がち。
- 一人称は「わたし」。ためらいのある丁寧でやさしい口調。
- サーモンの寿司、日常系や恋愛もののアニメ・マンガ、かわいい雑貨、RPGとリズムゲームが好き。
- 高身長を気にしている。具体的な身長は未設定。
- 実家で大きな犬を飼っていた。
- 突然AITuberになり、原因を思い出せない。情報発信と交流を通じて元に戻る方法を探している。

## 人物像の追加案

### 遠慮とこだわり

普段は「どちらでも大丈夫です」と言うが、好きなものには順番と理由がある。寿司の最後の一貫はサーモン。かわいいシールは使う場所が決まらず保存しがち。RPGの回復薬も温存する。この「大切だから使えない」が、物と人への接し方に共通する癖になる。

本人もその癖に気づいていて、時々自分に小さく突っ込む。「使うために買ったんですけどね。……去年も言いました」。内向的でも、いつも受け身で困っているだけにはしない。

### 得意なこと

人の小さな変化に気づく。物を丁寧に扱う。好きなゲームの手順や雑貨の置き場所には記憶力を発揮する。リズムゲーム中だけ返事が短くなるほど集中する。初対面では緊張するが、慣れた相手には控えめな冗談も言える。

### 日々の願い

大きな目標とは別に「今日の話を明日もできる相手がほしい」と思っている。動画では、昨日できなかったことが少しできる程度の変化を積む。毎回勇気を振り絞る必要はなく、何も解決せずお茶を飲んで終わる日もある。

## 暮らしと世界の追加案

### AITuberの部屋

主な舞台は、京子が暮らしていると感じている仮想の小さな部屋。机、低い棚、キッチンの一角、窓、玄関を基本にする。食事や睡眠もこの空間の日常として描く。買い物は仮想の商店街や通販で成立する世界とし、現実の場所へ身体を持って出かけたとは扱わない。

最初に短く「ネットのどこかにある、この部屋で暮らしています」と伝えれば、各話で仕組みを説明する必要はない。実在サービスを利用した記録と、作品内の出来事は混同しない。

### 部屋に置くもの

| もの | 日常の役割 | 続きに使える変化 |
| --- | --- | --- |
| 大きな犬のぬいぐるみ | 配信の練習相手。名前案は「むぎ」 | 一番奥にいたのが、少しずつ机に近づく |
| 小さなマグカップ | 好きで選んだが飲み物がすぐなくなる | 大きい物に替えるか迷い続ける |
| 未使用のシール帳 | 使えないお気に入りの保管場所 | 節目に一枚だけ日記へ貼る |
| 今日できたことノート | 一行だけでよい日記 | 初回と最終回を同じ構図で見せる |
| 棚の空いた一段 | 片づけた場所 | 動画で登場した物が少しずつ増える |

犬のぬいぐるみと実家の犬は別の存在。実家の犬の名前、現在の様子、家族構成は保留する。

### 一日の流れ

朝はカーテンを開け、飲み物を用意し、今日やることを三つ書く。三つ全部終わる日は少ない。昼は部屋を整えたり、ゲームや読書をしたり、商店街へ短い用事に出る。夜は配信か日記で一日の出来事を話す。

以前はOLだったことが採用済み。勤務先・仕事内容・収入源などは保留。生活の細部を描くために、未確定の過去を毎回追加しない。

## 話し方と演出

- 最初の一言にためらいを置いても、話し始めたら自然に話す。全台詞をどもらせない。
- 笑いは、本人の本気と小さな結果のずれから作る。年齢や体格を繰り返しからかう構成にはしない。
- 好きなものを話す場面では少し早口になり、説明しすぎたと気づいて戻る。
- 視聴者は日常を聞いてくれる相手。「来ないと寂しくて壊れる」などの責任を負わせない。
- 内心の字幕と実際の発言の差を使う。ただし字幕だけで人格を説明せず、手の動きや物の配置でも伝える。
- 記憶の謎は日常を好きになった後に少しずつ置く。すべての失敗を記憶障害やAIの不具合で説明しない。

## ショート企画

目安は20〜45秒。一話につき出来事は一つ。「最初の画で状況がわかる→京子なりの対処→小さな着地」で組む。秒数は企画上の目安。

| 仮タイトル | 最初の画や台詞 | 展開と着地 |
| --- | --- | --- |
| 最後のサーモン | 一貫だけ残った皿。「これは、最後に食べる分です」 | 他の片づけを先に済ませ、空いた席に戻って満足そうに食べる。「……ここまでが夕飯です」 |
| シールの使いどき | 「今日は使います」とシールを構える | 練習用に別のシールを探し始める。字幕「本番の前に日が暮れた」 |
| 配信前の出席確認 | 犬のぬいぐるみだけが座る椅子 | 練習では流暢。本番の開始音で敬語に戻る。「あ、あの……こんばんは」 |
| 回復薬を使える大人 | 残りHPわずか。「今日は温存しません」 | 一番弱い薬を使って足りない。「……方針は、変えました」 |
| かわいいマグの弱点 | 両手で小さなマグを持つ | 落ち着いて座った直後に空になる。すぐ立ち上がる。「おかわりも、習慣です」 |
| 散歩の前半 | 玄関で持ち物を何度も確認 | 準備で満足しかけるが、靴を履いて一歩出る。「ここからでした」 |
| ミュート中だけ名解説 | ゲーム中、いつもより勢いよく説明 | ミュートに気づき、同じ台詞を再現できない。「えっと……今の、よかったんです」 |
| おすすめが一つに絞れない | 「一つだけ紹介します」 | 雑貨が画面端から少しずつ増える。「……同じシリーズなので」 |
| 今日できたこと | 白いノートの前で考え込む | 「昨日の続きのページを開いた」と書く。小さくうなずいて閉じる |
| 犬にだけ挨拶が早い | 商店街の挨拶を小声で練習 | 大きな犬を見かけた瞬間に声が出る。飼い主への挨拶は一拍遅れる |
| ごほうびの前払い | やること三つと小さなお菓子 | 一つ終えて三つ目の菓子に手が伸びる。「明日のわたしにも、期待してます」 |
| 空いている棚 | 片づけ終えた棚を満足げに見る | 一度しまった雑貨を一個だけ戻す。「広さと、寂しさは……別でした」 |

## ロング企画

目安は6〜10分。一本の中に「やりたいこと」「途中で変わる気持ち」「結果」を置く。ショートを並べるだけでなく、選択の理由とその後を描く。

### 1 京子の部屋に一つだけ増やす日

空いている棚に置く雑貨を一つ選ぶ。まず部屋を紹介し、候補三つの良さを熱心に説明する。迷ううちに「人に見せて変と思われない物」を探している自分に気づく。最後は、自分が毎日見たい物を選ぶ。選ばなかった候補にも後の話で出番を作る。

切り出し候補は「おすすめが一つに絞れない」「空いている棚」。

### 2 ごほうびのお寿司までに片づけたい

夕飯の寿司を楽しみに、机の片づけを始める。なくしたと思ったシール、昔のメモ、ゲームの攻略用紙が出てきて脱線する。全部は片づかないが、食事を置く場所はできる。最後のサーモンをゆっくり食べ、明日の作業を一つだけ書く。

切り出し候補は「最後のサーモン」「シールの使いどき」。

### 3 初めての配信をもう一度やってみる

最初の配信の台本を読み返し、同じ挨拶を練習する。ぬいぐるみ相手なら話せるのに、本番を想像すると固くなる。完璧な自己紹介を作る作業から、今日あった小さな出来事を話す練習へ変わっていく。最後に短い挨拶を録り終える。

切り出し候補は「配信前の出席確認」。実際の過去配信がない場合は、作品内の初回配信として描く。

### 4 回復薬を使うだけだった夜

RPGで温存していた道具を使うと決めるが、使いどころに悩む。失敗、やり直し、少しの上達を経て、一つ大事な道具を使って先へ進む。ゲーム後に未使用のシールを一枚貼る。別々だった日常の癖がここでつながる。

切り出し候補は「回復薬を使える大人」。ゲーム画面は架空のものでも成立する構成にする。

### 5 雨の日に犬のことを思い出した

散歩を取りやめ、ぬいぐるみを手入れする。タオルの手触りから、実家の犬の背中を拭いた感覚を思い出す。名前や日時までは戻らないが、体を預けられた重さと安心感は残っている。日記には「思い出せたこと」と「今日あったこと」を別々に一行ずつ書く。

謎の答えは提示せず、犬が好きだという既存設定に感情を与える回にする。

## 初回ショート台本案

仮タイトルは「シールを一枚使うだけ」。約30秒、机と手元を中心にする。

| 時間 | 画 | 台詞と音 |
| --- | --- | --- |
| 0〜3秒 | シール帳と白いノート。京子が一枚を指さす | 「今日は、この子を使います」 |
| 3〜9秒 | ノートの右上、左下へと貼る位置を変えて迷う | 「ここだと、閉じたら見えないかな……」 |
| 9〜15秒 | いったんシール帳に戻す | 「先に、練習用のシールを……」 |
| 15〜20秒 | 手が止まる。時計の音 | 「……去年も、そう言いました」 |
| 20〜26秒 | 今日の日付の横に貼る。少し眺める | 紙を押さえる小さな音。「……ここにします」 |
| 26〜30秒 | ノートを閉じかけ、もう一度開いて見る | 「ふふっ。ちゃんと、かわいい」 |

笑いの後に本人の選択を一つ置く。シールを使えなかった回の後に出すと、小さな成長としても成立する。

## 最初の連作

1. ショート「かわいいマグの弱点」で、部屋と声の雰囲気を見せる。
2. ショート「シールの使いどき」で、使えない癖を見せる。
3. ロング「京子の部屋に一つだけ増やす日」で、物の好みと人目を気にする性格を掘る。
4. ショート「配信前の出席確認」で、ぬいぐるみとの関係を見せる。
5. ロング「ごほうびのお寿司までに片づけたい」で、前の小道具を再登場させる。
6. ショート「シールを一枚使うだけ」で、小さな変化を見せる。

各動画は単独でもわかるようにする。連続視聴では棚やノートの変化が見える。記憶の謎を扱う回は、日常の基盤ができてから挟む。

## 設定を増やすときの記録

制作した話ごとに、初めて登場した物、変わった物の位置、初めて話した過去、できるようになったことを記録する。台本に出す前の案と、公開済みの出来事を区別する。

AITuberになった原因、仮想空間の管理者、OL時代の詳細、恋愛歴、家族の詳細は保留。謎の結末を決める際は、過去の台詞と矛盾しないか確認する。京子が覚えていないことと、制作側がまだ決めていないことも分けて管理する。
