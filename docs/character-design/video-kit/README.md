背景・字幕・演出の試作。正式なデザイン採用は未決定。[ADR 0014](../../adr/0014-video-visual-kit.md)を参照。

## 背景PNG

| 背景 | ファイル名の先頭 | 用途の目安 |
| --- | --- | --- |
| やわらかな月あかり | `kyoko-background-soft-` | 自己紹介・カウントダウン |
| 紺色の夜 | `kyoko-background-night-` | 落ち着いた挨拶・前日の告知 |
| あたたかな紙色 | `kyoko-background-paper-` | 好きなものや日常の紹介 |

各名前に `1080x1920.png`（縦）、`1920x1080.png`（横）、`1080x1080.png`（正方形）が続く。計9枚。人物・字幕・ロゴを含まないので動画編集ソフトでも利用できる。キャラクターの部屋設定を確定するものではなく、抽象的なスタジオ背景。

## 使い方

1. ルートで `npm run studio` を実行し、`http://localhost:4173/frontend/studio/` を開く。
2. サイズ・背景・画角を選ぶ。
3. 「背景・字幕・演出」で紺色か白の角丸字幕を選び、必要なら見出し・残日数・採用ロゴを設定する。
4. 「やさしく登場」は収録開始時に0.7秒のフェードを再生する。
5. 収録の終わりに「白へフェード」を選び、白くなってから停止する。「演出を再生」で確認を繰り返せる。
6. 「映像をPNG保存」で告知静止画、「背景だけPNG保存」で背景3種類を書き出せる。

字幕は1行につき1つの台詞を手動で送る。新しい角丸字幕は折り返しと縮小に対応するが、読みやすさのため1〜2行程度の短い台詞を推奨する。音声との自動同期は未実装。

紺 `#263951` と白を共通色にする。字幕は下端約10%を空け、ロゴは左上、残日数は右上、見出しは左側へ配置。装飾は端へ寄せ、人物の後ろは静かに保つ。

実装は `frontend/studio/visuals.js`。PNGは同じCanvasから生成。外部画像サービスや追加フォントを使わない。`frontend/studio/smoke-test.cjs` で背景9枚の再生成、3画角、録画・保存、フェード、OBS同期を確認できる（PlaywrightとEdgeを使用）。

頭頂部・目元などを段階公開するマスク、自己紹介の完成動画、効果音・BGMは今回のセットには含まない。
