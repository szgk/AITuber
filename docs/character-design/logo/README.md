# 望月京子 ロゴ試作

## 正式採用ロゴ

[kyoko-logo.png](kyoko-logo.png) を正式ロゴとして使用する。第6案を変更せず複製した背景透過PNG。採用記録は[ADR 0012](../../adr/0012-adopt-kyoko-logo.md)を参照。以下の「未採用」「採用前」は各試作時点の記録であり、第6案はその後正式採用された。

## 第6案：花びらの紺枠を太く調整

- [背景透過PNG](kyoko-logo-v6-petal-bold-outline.png)
- 内蔵画像生成ツールで第5案を編集。
- 生成指示：対象の花びらの紺色の外枠のみを約3倍の太さ（生成時の目安18〜24ピクセル）にし、周囲の太い文字と釣り合うように調整。斜めの花びら、ピンクの中心、内側の白枠を維持。他の文字・装飾・配色・配置・背景透過を維持する。
- 第5案を保持し、第6案は最終採用前の試作として保存。

## 第5案：元の花びらに紺色の外枠を追加

- [背景透過PNG](kyoko-logo-v5-petal-navy-outline.png)
- 内蔵画像生成ツールで第3案を編集。
- 生成指示：「月」の内側下部の斜めのピンクの花びらを維持し、その白枠の外側に明瞭な紺色の輪郭を追加。花びらを横棒に変形させず、その他の文字、配色、配置、リボン、装飾、背景透過を維持。ロゴ全体への追加外枠ではなく、対象の花びらのみを編集する。
- [修正方針のADR](../../adr/0011-logo-petal-outline.md)。画像自体は最終採用前の試作。

## 「月」の横棒の比較案（未採用）

内蔵画像生成ツールで第3案を編集し、3案を作成した。ポップな書体と紺色ベースは維持する。ユーザーの修正意図は、花びら部分を文字の一部として読みやすくすること。

- [A：小さな花びら](kyoko-logo-v4-a-petal.png)：紺の横棒に小さなピンクの花びらを添える。
- [B：横長の花びら](kyoko-logo-v4-b-petal-bar.png)：ピンクの花びらを横に伸ばし、紺の縁で文字につなぐ。
- [C：装飾なし](kyoko-logo-v4-c-plain-bar.png)：内部の花びらをなくし、通常の紺の横棒にする。

生成指示：第3案を参照し、「月」の下側の内側横棒だけを上記の各形状に変更。その他の文字、英字、配置、リボン、外側の装飾、白縁、背景透過を維持する。画像生成により細部には差がある。いずれも比較用の提案で、最終採用は未決定。

いずれも未採用の試作。内蔵画像生成ツールを使用し、背景透過PNGで保存した。

- `kyoko-logo-v1.png`: 紺主体の初案。
- `kyoko-logo-v2-pop.png`: 「もっとポップな感じで」という指示に対応した第2案。
- `kyoko-logo-v3-pop-navy.png`: ポップな書体を保ち、文字を紺色ベースに変更した第3案。

## 第3案の生成指示

内蔵画像生成ツールで第2案を編集。配色のみを変更し、丸く太い文字形、配置、リボン、汗、星、表記を維持するよう指定。日本語4文字と英字を深い紺色（目安 #20334F）にし、白い縁取りを保持。ピンクと水色は小さな装飾に限定し、全体は紺と白を主体にする。背景透過、追加文言なし。書体と紺色ベースの方針は[ADR 0010](../../adr/0010-logo-pop-type-navy-color.md)に記録。

## 第2案の生成指示

初案を編集対象とし、「望月京子」「MOCHIZUKI KYOKO」の表記を保持。丸く太いカスタム文字、弾む配置、ピンクと明るい水色、紺の輪郭と白の外縁へ変更。紺のリボンと汗のしずくを残し、長い優雅な曲線装飾を減らす。少数の星・点を加え、サムネイルでも読める一つのロゴとする。背景は透明、追加文言なし。
