# 望月京子の追加動画企画 2026年10月23日 第1回

全案の状態は提案。既存設定のゲーム好き・雑貨好き・遠慮がちな性格を使用する。部屋での日常表現は [初期設定案](../kyoko-daily-life-and-video-ideas.md) に依存する未採用の舞台案。新たな恒久設定や過去の出来事は確定しない。[運用ADR](../adr/0003-recurring-video-ideation.md) に基づく初回分。

## S20261023-01 セーブしたか確かめるために

30秒のショート。ゲーム好きという既存設定を使う。一話限りの行動としてセーブ後の確認を描く。

| 時間 | 画と動き | 台詞と音 |
| --- | --- | --- |
| 0〜4秒 | 架空RPGのセーブ完了表示と、終了操作に伸びる手 | 「ちゃんと保存しました」 |
| 4〜10秒 | 手が止まり、再びセーブ画面へ | 「……しました、よね？」 |
| 10〜17秒 | 同じ場所に再保存し、完了表示を指さす | 「今度は、見ました」 |
| 17〜24秒 | 確認用にスクリーンショットを撮る。保存音 | 「これで安心……あ」 |
| 24〜30秒 | スクリーンショットの保存先を探し始める | 「写真は、どこに保存されたんでしょう」 |

必要素材は京子の上半身、机、独自のゲームUIと画像保存表示、操作音。記憶の謎や病気とは結び付けず、慎重さの小さな脱線として演じる。既存の回復薬企画とは、ゲームを終える場面と確認の連鎖で差を付ける。

## S20261023-02 紹介する物より長い注意書き

35秒のショート。雑貨好きと遠慮がちな性格を使う。

冒頭は小さな雑貨一つと「今日は、これの好きなところを」。手書きの紹介札に「個人の感想です」「色は画面と少し違うかも」などを加えるたび、肝心の雑貨が札に隠れていく。途中で自分で気づき、札をすべて横に置く。結末は「丸くて、かわいいです」と一言だけ伝え、ほっと笑う。

必要素材はオリジナル雑貨一つ、紙札、机、手元差分。紹介候補が増える既存案と異なり、一つの物への説明を削る展開にする。新しい固定設定は不要。

## S20261023-03 休憩中の指だけ忙しい

25秒のショート。リズムゲーム好きという既存設定を使う。

冒頭はゲームを閉じる画と「少し、手を休めます」。飲み物を用意して座ると、カップを置く音につられて指先が机でリズムを刻む。自分で気づき、両手でカップを持つ。結末は足先が拍子を取り始めたのを見て「……曲が、頭に残ってます」。

必要素材は机、カップ、指と足先の差分、短い自作リズム。実在曲やゲーム画面は不要。カップの容量を扱う既存案とは異なる身体の動きで見せる。新しい固定設定は不要。

## L20261023-01 好きな音を三つだけ録る午後

8分のロング。部屋の音を短い動画にするという、その回の目的を置く。ゲームと雑貨への関心を利用し、録音が得意という設定は加えない。

| 時間 | 展開 |
| --- | --- |
| 0:00〜0:25 | 再生した録音から大きな衣擦れ音。「……今の、わたしの袖です」。今日の目的を伝える |
| 0:25〜1:30 | 候補を選ぶ。ページをめくる音、カップを置く音、ゲームのボタン音 |
| 1:30〜3:00 | 小さな音を録ろうとして息を止め、動くと袖の音が入る。袖をまくり、近すぎたマイクを動かして再挑戦 |
| 3:00〜4:30 | 同じ音でも置く場所や動かす速さで違うと気づく。音を聞き比べる場面には無言の間を作る |
| 4:30〜6:00 | 整った録音だけでは物足りず、音を聞いたときの短い感想を自分の声で添える |
| 6:00〜7:20 | 三つの音と感想をつないだ短い作品を再生する。過剰な失敗集にせず、完成まで見せる |
| 7:20〜8:00 | 録音を止めたつもりで「これ、ちょっと好きかも」と話す。残っていたその声も、今日は消さずに終える |

冒頭の失敗から、音そのものと自分の声を面白がる変化につなげる。必要素材は部屋一景、手元三種類、マイク、簡単な録音画面、実際に用意した自作効果音。切り出し候補は「袖の音が主役になった録音」「同じカップで三つの音」。独立ショート3案とは別の場面を使う。

追加設定案は不要。録音された言葉を採用したからといって、恒久的な性格変化や過去の回復を断定しない。
