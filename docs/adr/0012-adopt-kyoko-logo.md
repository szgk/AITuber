# ADR 0012: 第6案を望月京子のロゴに採用する

- 状態: 採用
- 日付: 2026-10-23
- 決定者: ユーザー

## 背景

ポップな書体と紺色ベースのロゴについて、「月」の花びらに白枠と太い紺枠を付けた第6案を提示した。ユーザーから「ロゴとして保存」と指示された。

## 決定内容

第6案を望月京子の正式ロゴとして採用し、背景透過PNGを `docs/character-design/logo/kyoko-logo.png` に保存する。第6案の画像を変更せず複製する。

## 理由

ユーザーが直前に提示された第6案の保存を指示したため。

## 影響

- 動画やデビュー告知に用いるロゴの参照先を確定する。
- ADR 0011の最終採用未決定の状態を本ADRで解決する。書体・配色・縁取り方針は継続する。
- 比較用の旧案と生成指示は制作経緯として保持する。
- 外部への投稿・公開はこの保存では実施しない。
