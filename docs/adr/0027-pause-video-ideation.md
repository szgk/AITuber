# ADR 0027 動画案の自動生成を一時停止する

- 状態: 採用
- 日付: 2026-10-25
- 決定者: ユーザー

## 背景

ユーザーから「一旦自動生成はストップ」と指示された。対象はこのスレッドで継続していた望月京子の動画案の定期自動生成とする。

## 決定内容

自動化 `automation-3` を一時停止する。再開指示があるまで動画案の定期生成を再開しない。既存の企画と再開に使うタスク設定は保存する。

## 理由

ユーザーの停止指示に従い、継続生成を止める。「一旦」という指定に合わせ、タスクは削除せず停止する。

## 影響と対応状況

- 自動化更新ツールで `status: PAUSED` の成功応答を確認した。
- [ADR 0003](0003-recurring-video-ideation.md)の定期実行方針を一時停止へ部分置換する。企画形式と履歴は保持する。
- 今回は新しい動画案を生成しない。再開時期は未定。
