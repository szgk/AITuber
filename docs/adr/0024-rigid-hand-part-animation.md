# ADR 0024: 手は歪ませずパーツ単位で揺らす

- 状態: 採用（ユーザーの指摘と修正方針）。実出力の判定はレビュー記録で管理。
- 日付: 2026-10-24
- 決定者: ユーザー

## 背景

ユーザーから「手の揺れは歪ませて動かせるのではなくパーツごと揺らす形のほうが自然」と指摘された。告知動画の初期実装は手元への局所メッシュ変形で手振りを表現し、指の長さや掌の輪郭まで変化していた。

## 決定内容

- 手の揺れに局所メッシュやガウス変形を使わず、指・掌・輪郭の形を保ったパーツ単位の回転・並進を用いる。
- 03・15の挨拶は原画から手を切り出し、手首を支点とする剛体回転で振る。頭・顔・髪の変形を手パーツへ渡さない。
- 元の手があった下絵はimagegenで補完し、元の手が二重に残らないようにする。顔など補完不要の領域は原画を保持する。
- カードを持つ04・05、襟元の11、頬へ指を添える13、両手を胸元で握る14の手への局所揺れを除去し、手の内部を固定する。これらを今後揺らす場合もパーツ単位にする。
- 袖口と手首の接続、指の形、画面端での欠け、旧手の残像を実動画と拡大画像で確認する。03は小指が画面外へ切れない振幅に制限する。

## 理由

手を柔らかい面として歪ませると関節や指の長さが変化し、不自然に見えるため。手振りの回転と身体・顔の揺れを別の変換として扱う。

## 影響・対応状況

- [告知動画のADR 0022](0022-debut-video-character-animation.md)の手に対する局所変形を部分置換。顔・目・跳ね毛の演技は継続する。
- 元動画15本を保持し、修正版は `outputs/debut-motion-preview-v2/` へ別出力する。変更対象は03・04・05・11・13・14・15。
- 手の切り出し素材と補完下絵は `assets/debut-animation/rigid-hands/`。補完下絵は組み込みimagegen、切り出しとアニメーション合成は制作コードで実施。
- 指間距離と面積の不変性、手首の追従、保持する手の無変形を回帰検査する。
- 声付き本編が未完成である状況は継続。今回の出力も無音の動作確認版と明記する。

## 検証結果（2026-10-24）

- 指間距離・面積の不変性、手首支点の追従、保持する手の無変形の3検査が合格。口の角度・目元不変性の既存2検査も合格。
- 変更7本の最終MP4の全編60連続フレーム、拡大画像を確認。03・15は手の24連続拡大フレームで、指5本と掌の形、袖口との接続、元の手の残像がないことを確認した。
- 03の手の主要アルファ領域が180フレームすべてで画面内に収まることを検査。未変更8本の動画はSHA-256が旧版と一致することを確認した。
- 修正対象7本は無音確認版として視覚合格。15本を再梱包し、一覧とZIPを修正版フォルダーに保存する。声付き本編は未完成。
