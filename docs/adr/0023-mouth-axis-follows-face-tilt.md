# ADR 0023: 開いた口の向きを原画の顔の傾きへ合わせる

- 状態: 採用（口の方向の修正と初回ショートv6制作）
- 日付: 2026-10-23
- 決定者: ユーザー

## 背景

ユーザーから「口の向きを顔の傾きに合わせてください」と指定された。ADR 0022で口の中心と輪郭は修正したが、開いた口の楕円は水平のままで、原画の傾いた顔・閉じ口と軸が一致していなかった。

## 決定内容

- 各姿勢の原画の閉じ口の左右端から口角軸を測り、開いた口の軸を同じ角度にする。全姿勢へ同じ固定角を流用しない。
- 画像座標で立ち姿は約−12.80度、髪へ手を伸ばす姿勢は約−13.22度、耳元へ手を添える姿勢は約−14.01度。右の口角が上がる方向で、原画の顔の傾きに合わせる。
- `mouthAxis` に原画上の左右の基準点、`angleDegrees` に角度を保存する。口の輪郭・内側・舌の描画を同じ局所座標で回転させる。
- 中心位置を固定し、口を描いた後は顔と同じ身体の揺れ・カメラ変換へ渡す。口の開閉と頭の動きを別々の向きにしない。
- ADR 0022の高解像度描画・姿勢別の口位置、ADR 0021の目元不変・音素同期・読み・ライトの遮蔽を継続する。音声は変更しない。
- 初回ショートv5と台本を履歴として残し、v6を別出力して最終MP4をレビューする。

## 理由

顔が傾いたまま口だけ水平になる不自然さを取り除き、閉じ口・開口・姿勢切替で顔に対する口の方向を揃えるため。

## 影響

- ADR 0022の開いた口の向きだけを本ADRで部分置換する。位置と画角の決定は継続する。
- 回帰検査で各原画の口角軸と描画された開口の主軸が一致することを確認する。開き具合を変えても向きが変わらず、口以外の画素も変えない。
- 告知動画についての同様の方針は[告知動画のADR 0022](0022-debut-video-character-animation.md)を参照。本作業の出力対象は初回ショート。
- 新出力は `outputs/shorts/short-001-v6/`、旧台本は `projects/short-001/storyboard-v5.json` に保存する。

## 検証結果

- v6最終MP4（23.03秒・1080×1920・30fps）の各場面・拡大・目口の7連続フレームを確認し、3可視ポーズの開いた口が閉じ口・顔の傾きへ揃うことを確認した。
- 角度の一致を含む回帰検査4件と視覚・技術検証が合格。口以外の画素不変、中心位置、音声の同一性も維持した。
