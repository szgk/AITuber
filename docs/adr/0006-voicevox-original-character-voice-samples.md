# ADR 0006: 創作キャラクターへの声当てを許可するVOICEVOX音声の比較

- 状態: 採用（比較試作の方式のみ。声・本番エンジンは未採用）
- 後継: [ADR 0007](0007-adopt-kyoko-voice.md)でサンプル⑥の声・エンジンを採用。上記の未採用状態は比較実施時の記録として保持する。
- 日付: 2026-10-23
- 決定者: ユーザー（許可された音声でのサンプル作成を依頼）

## 背景

気弱で少し震える声の方向性に対し、Windows音声による初期試作に続き、ユーザーからオリジナルキャラクターとしての利用が許可されたVOICEVOX音声のサンプル作成を依頼された。

## 決定内容

公式規約で創作キャラクターへの声当てが明示的に許可されている冥鳴ひまり・雨晴はう・ナースロボ＿タイプＴを比較する。この端末のインストール済みVOICEVOXエンジンを127.0.0.1の専用ポート50031で起動し、同一の自己紹介を合成する。外部音声サービスには送信しない。

1. 冥鳴ひまり・ノーマル
2. 雨晴はう・ノーマル
3. ナースロボ＿タイプＴ・ノーマル
4. ナースロボ＿タイプＴ・恐怖
5. ナースロボ＿タイプＴ・内緒話
6. 3に微小な音高・音量の揺れを加えた後処理版

1〜5はVOICEVOXの話速と抑揚の調整のみとする。6は出力音声の加工も明示的に許可するナースロボ＿タイプＴを使用し、声質変換モデルや機械学習を使用せず、信号処理で微小な揺れを加える。

WAV、合成クエリ、エンジンバージョン、台詞、音声ID、加工の有無、規約URL、クレジットを `outputs/voicevox-samples/` に保持する。試聴ページにもクレジットと規約を掲載する。比較結果による採用判断は別途行う。

## 理由

声の演技スタイルと声質の違いを、同じ台詞で比較できる。公開動画への利用条件の確認と、試作による音声の選定を両立する。

## 影響・利用条件

- VOICEVOX本体と個別音声の規約を併せて適用する。公開時は使用した音声が分かるクレジットを掲載する。
- 冥鳴ひまりは公式Q&Aでオリジナルキャラへの利用を許可し、個人・法人の商用・非商用利用を認めている。
- 雨晴はうは一次・二次創作キャラクターへの声当てに許可・確認不要と明記している。VOICEVOXの表示は必須。音声のR18利用等は禁止される。
- ナースロボ＿タイプＴはVOICEVOX音声の項で創作キャラへの声当てと出力音声加工を認めている。企業による商用利用には連絡が必要。音声とキャラクター・公式画像の利用条件は別であり、本試作では公式画像を使用しない。
- 各規約の禁止用途は引き続き適用される。2026-10-23時点の公式ページを確認したもので、以後の公開時にも条件を確認する。
- ADR 0005の声の方向性は継続する。Windows音声の初期試作は保存し、本ADRは比較候補の追加として扱う。
- 今回の比較はローカルエンジンによる音声生成のみであり、収録室への音声合成統合や自動字幕生成は含まない。
