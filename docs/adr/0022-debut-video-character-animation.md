# ADR 0022: 採用した告知ラフから顔・目・手・跳ね毛が動く声付き動画を作る

- 状態: 採用（ユーザー指定と動画制作）。最終動画の品質は視覚レビュー結果で管理。
- 日付: 2026-10-23
- 決定者: ユーザー

## 背景

ユーザーから以下の指示を受けた。

- 「涙が大きすぎるのでもう少し小さくして普通の楕円でいい」
- 「それぞれの画像は良さそうです！これで動画にしていきたいです」
- 「頭や顔も動かすが、目のグルグルを動かしたり目のハイライトが少しうるうるしたり」
- 「シチュエーションに合わせて、手を振ったり覗き込むときは覗き込むように動いたりして下さい」
- 「向かって右上の髪の毛のくせ毛もアニメーションで動くようにする」「よくあるアニメキャラのアホ毛のようにイヌの尻尾のように動かしたい」

## 決定内容

- 追加指摘「口が顔の傾きにかかわらず水平になってしまってないか」への対応: 初期実装が水平な口を描いていたことを確認。口の局所座標を各原画の口角軸へ回転して描き、頭・顔と同じ変形へ渡す。開閉で顔の傾きと口の軸を切り離さない。角度と口以外の不変性を回帰検査する。実動画の再レビューまでは修正済み動画として扱わない。
- ADR 0020の各画像ラフの構図・表情を動画制作の基準として採用する。14の涙は小さな通常の楕円とし、白ベタ・黒輪郭を継続する。
- デビュー14日前〜当日の15本を、顔中心の声付き短編として制作する。投稿日時や外部公開は別で、未確定。
- 頭・顔に小さな動き、09・14のぐるぐる目に回転、開いた通常目のハイライトに発話と独立した小さな揺れを付ける。
- 03・15では手を振り、08では目隠しから覗き込む。小道具や考え込みなど各シチュエーションに沿う動きを付ける。
- 向かって右上の跳ねたくせ毛を、付け根からつながるアホ毛として、犬の尻尾のように揺らす。感情に応じて振幅・周期を変えるという具体値は制作上の解釈とする。
- 口パクは採用済み音声の音素長に同期させ、口の描画によって目を変えない。今回の目の動きはユーザー指定の演技として口パクと独立させる。
- 声はADR 0007の採用済み設定を用いる。字幕と音声を付け、日ごとの短い台詞を作品原稿として保存する。

## 理由

静止画の移動だけでなく、目・手・髪の動きから性格と状況が伝わる短編にするため。段階公開と顔を見せる方針は維持する。

## 影響・対応状況

- 後継: [ADR 0025](0025-smooth-mouth-opening.md)で口の開閉量と輪郭を連続的につなぐ。口角軸、目元の独立性、手の剛体回転は維持する。
- 後継: [ADR 0024](0024-rigid-hand-part-animation.md)で、手に対する局所メッシュ変形を廃止し、パーツ単位の回転・並進へ部分置換する。旧版とレビューは履歴として保存する。
- ユーザーから「それぞれの動画を作成」と再指定された。3本の動作確認だけではなく、01〜15の各画像に対応する個別動画を出力対象にする。音声の接続待ちがある場合も、無音の動作確認版と声付き本編を区別し、無音を声付き完成品と報告しない。
- ADR 0020の「ラフ未採用・動画未制作」は本ADRにより制作へ移行。涙の大きさと形は本ADRで部分置換し、旧ラフは履歴保存する。
- 画像参照から動画用素材をimagegenで再制作し、`assets/debut-animation/` に保存する。右上の毛先を動かす余裕と、単体で使用できるコマを用意する。
- `tools/debut_animation.py` は局所メッシュで頭・顔・手・跳ね毛を別に変形し、ぐるぐる目とハイライトを独立描画する2D方式。生成AIによる連続動画や3Dリグではない。
- 出力先は `outputs/debut-videos-v1/`。実動画の各場面と連続フレーム・目元・手元・髪の境界をレビューし、未レビュー・不合格のものを完成扱いにしない。
- 画角に足・床・家具がない場合、その項目は対象外として記録する。
- 本ADRの記録時点では制作中。具体的な納品状況は出力先の記録へ追記する。

## 口の傾きへの対応結果

- 10画像の口の描画角を原画ごとの口角軸に照合し、誤差2度以内を検査。09・14・15では口の開閉で目元が変わらないことも検査した。
- 修正後の09・14・15を6秒の無音・テスト用開閉プレビューとして出力。実MP4の全編60フレームと顔の拡大画像を確認し、口の傾きへの追従を確認した。
- 声付き15本は未完成。ローカルVOICEVOXへの接続はサンドボックスで拒否され、制限外での生成プロセスは出力を得られていない。動作確認動画に声・音声同期の合格を付けない。

## 個別動画15本の出力状況

- ユーザーの「それぞれの動画を作成」に対応し、01〜15の各ラフから6秒・1080×1080・30fpsの無音動作確認版15本を作成した。声付き本編と音声同期は未完成であり、完了扱いにしない。
- 音声生成と接続確認を制限外実行で再試行したが、実行結果・合成音声ファイルを得られなかった。別音声への無断変更はしない。
- 原画の口を実画像で再確認し、06・07・10〜14の位置と角度を補正。07で口を消すための肌色取得が元の口に重なっていた問題を修正し、ピンクの矩形が残らないことを再出力後に確認した。
- 全15本の各180フレームをデコード検証。各実MP4の全編60連続フレームと顔・手・髪の詳細を目視確認し、無音動作確認版としての視覚レビュー、検証結果、動画と証拠のSHA-256を保存した。足・床・家具は画面に存在せず対象外。
- [15本の一覧・個別保存](../../outputs/debut-motion-preview/index.html)、[15本のMP4 ZIP](../../outputs/debut-motion-preview/debut-motion-15-videos.zip)。声付き本編の保存先とは明確に区別する。
- 動作は局所メッシュを使う2Dアニメーションで、静止画を新しい向きへ立体的に回り込ませる方式ではない。
