# ADR 0009: ロゴをポップな方向で試作する

- 状態: 採用（ポップな方向への調整指示）。個別のロゴ案は未採用。
- 後継: [ADR 0010](0010-logo-pop-type-navy-color.md)で書体・配色の未決部分を更新。ポップな方向性は継続し、具体化部分は後継に置換する。
- 日付: 2026-10-23

## 背景

ADR 0008に基づきロゴ制作を開始した。最初の紺を主体にした案に対し、ユーザーから「もっとポップな感じで」と指定された。

## 決定内容

ロゴをよりポップな方向へ調整する。具体的な色・装飾・字形と最終ロゴはまだ採用されていない。

## 理由

ユーザーの希望する印象を次の試作へ反映するため。

## 影響

丸く太い文字、ピンクと水色、紺の縁取り、リボンと汗のモチーフを使った第2案を内蔵画像生成ツールで制作した。これらは試作上の提案であり、キャラクター設定の追加ではない。第1案も比較用に保持する。
