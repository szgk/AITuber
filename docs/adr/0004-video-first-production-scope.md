# ADR 0004: 合成音声を用いた動画制作を先行する

- 状態: 採用（制作方針。未実装機能の完成を意味しない）
- 日付: 2026-10-23
- 決定者: ユーザー

## 背景

デザインver1の収録システムについて、ユーザーから「基本動画や自動音声を使います」「将来的にはliveコメントを読んで返信しますがいまは動画だけから始めます」と指定された。マイクを使った生収録は基本運用ではない。

## 決定内容

- 当面の対象はショート・ロングの事前制作動画とする。
- 用意した動画素材と自動生成した音声（合成音声）を基本の入力として扱う。マイクは任意の補助機能とする。
- 制作の目標経路は、台本 → 合成音声 → 音声に同期するアバターと字幕 → 動画素材との合成 → 動画ファイルへの出力とする。
- ライブコメントの取得・読み上げ・内容に応じた返信は将来段階に分け、当面の動画制作の前提にしない。
- 音声合成エンジン、声、動画素材の配置方法、字幕の自動同期方式は未決定とする。特定サービスの採用や外部送信をこの方針だけで確定しない。

## 理由

まず事前制作動画でキャラクターの見せ方と制作手順を整える。ライブ連携を必要条件にせず、動画制作の改善を進められるようにする。

## 影響

現行の収録室は、音声ファイルの読み込み・口パク・手動字幕・録画を実装している。音声の自動生成、動画素材の取り込み・合成、字幕の自動同期は今後の実装対象であり、この記録時点では未実装。現行の録画は実時間で行う。

ADR 0003のブラウザ収録設計は継続し、制作の優先順位を本ADRで追加する。既存の設計や判断を置換するものではない。
