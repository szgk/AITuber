# ADR 0029: 現行デザインと設定を維持してVTuber風の描画にする

- 状態: 採用（制作方針）。生成した具体案は確認待ち。
- 日付: 2026-11-02

## 背景

ユーザー原文: 「この画像を参考にして今のデザインと設定は維持してからVtuberっぽいイラストにしたい」。

## 決定内容

現行ver1の黒い長いくせ毛、横へ跳ねる毛束、気だるい半目と気弱な表情、紺スーツ・白ブラウス・リボン・スカート・黒タイツ・パンプスと、32歳の元OLという人物設定を維持する。添付画像からは繊細な線、髪の艶、瞳と肌の描き込みを参考にする。参考人物の短髪、青い目、髪飾り、絆創膏、チョーカーは移植しない。

## 理由

京子の識別要素と人物像を残し、描画の精細さをVTuberの立ち絵に近づけるため。

## 影響・対応・未解決点

組み込みimagegenで全身と顔アップを並べた案を作成し、`docs/character-design/kyoko-vtuber-style-proposal-v1.png`へ保存した。元画像と設定は保持。生成案を既存素材へ採用・置換する判断は未確定。Live2Dのパーツ分けやリグは含まない。

実画像で黒い長髪と頭への接続、半目、スーツ、全身の靴までを確認した。頬染めは元の「薄くする」方針に比べてやや強く見えるため、確認時の留意点とする。背景との空間合成は行っていない。

## 追加指摘と対応（2026-11-02）

追加のユーザー原文: 「青薄めでおでこと目の中央に入れる」。青い影を薄くし、おでこから目の中央付近までに抑える指示として適用した。v5の濃い青い影を部分置換し、v6を別保存した。実画像で両方の顔の青が大幅に薄まり、頬に広がる青い影が除かれたこと、ぐるぐる目・大きな汗・顎先の滴の維持を確認。細い縦線は淡く残る。具体案全体の採用は確認待ち。
