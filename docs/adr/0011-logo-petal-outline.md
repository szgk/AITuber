# ADR 0011: 「月」の花びらを白枠と紺枠で縁取る

- 状態: 採用（修正方針。生成した第5案の最終採用は未決定）
- 日付: 2026-10-23
- 後継: [ADR 0012](0012-adopt-kyoko-logo.md)で第6案を正式採用。最終採用の未決定状態は後継に置換し、修正方針は継続する。

## 背景

「月」の下側の横棒に相当する花びらが文字の一部として見えにくいとの指摘を受け、複数案を比較した。ユーザーから、最初の桜の花びらを保ち、白枠の外側をさらに紺色の枠で囲むよう指示された。

## 決定内容

第3案の斜めの花びらを維持し、ピンクの花びら、白枠、紺色の外枠の順に縁取る。ポップな書体と紺色ベースはADR 0010を継続する。

ユーザーから「その線だけ他と比べて細すぎる」と追加指摘があったため、紺色の外枠は他の文字の線と釣り合う太さに調整する。縁取り方針を変更しない具体化として第6案を制作した。第6案の最終採用は未決定。

## 理由

元の花びらの印象を保ちながら、周囲の白い部分との境界を明確にするため。

## 影響

内蔵画像生成ツールで第5案を制作。横棒への置換案は比較資料として保持する。既存方針の置換ではなく、花びらの縁取りの具体化とする。
