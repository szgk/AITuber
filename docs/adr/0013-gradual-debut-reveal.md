# ADR 0013: デビュー前の投稿で姿と性格を段階的に見せる

- 状態: 採用（段階公開と性格を伝える方針のみ。具体的な原稿・日割りは提案）
- 日付: 2026-10-23
- 決定者: ユーザー

## 背景

ユーザーから、デビュー2週間前からのツイート内容と添付画像の内容を作り、最初は頭の上の部分だけが動く様子を出すなど、少しずつ姿を見せ、その中で性格も伝えるよう依頼された。

## 決定内容

- ADR 0008の2週間前からの告知を、部分的な姿の公開から徐々に全体を見せる構成にする。
- 初期の素材では頭頂部だけが動く演出を用いる。
- 投稿文と添付素材を組み合わせ、引っ込み思案、優しさ、好きなものなど既存プロフィールに沿う性格を伝える。
- 詳細な投稿文・画像内容・動きは関連資料に提案として保存する。日割り、1日1投稿、全身の前日公開、自己紹介ショートの当日公開は未採用。

## 理由

姿への興味と人物への親しみを同時に育てるというユーザーの意図を、制作時に参照できる形にするため。

## 影響

- ADR 0008を具体化する追加方針であり、既存の告知開始時期と1週間前からの動画公開は継続する。
- 静止画だけでは最初の動きを表せないため、冒頭用の短い動画素材も制作対象になる。
- 本作業では原稿と画面の制作指示を作成した。画像・動画の実制作と外部への投稿は未実施。
- 新しい日常設定や人格の実行用データへの反映は行わない。
