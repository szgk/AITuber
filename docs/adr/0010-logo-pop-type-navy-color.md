# ADR 0010: ロゴはポップな書体と紺色ベースにする

- 状態: 採用（書体・配色の方向性。第3案そのものは未採用）
- 日付: 2026-10-23

## 背景

第2案に対し、ユーザーが「書体はポップでいいが色は紺色ベース」と指定した。

## 決定内容

丸くポップな書体を維持し、配色は紺色をベースとする。ADR 0009の書体・配色の未決部分を本ADRで具体化する。

## 理由

ユーザーが第2案の書体を了承し、色の変更を希望したため。

## 影響

第2案を元に文字を紺色へ変更した第3案を制作した。白の縁取り、ピンク・水色の小さな装飾は試作として残している。最終画像の採用は未決定。旧案は保持する。
