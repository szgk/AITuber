# ADR 0015: 専用ポーズと空間レイヤーによる全身ショート制作

- 状態: 一部置換（お辞儀の演出と背景の作画は[ADR 0016](0016-hair-gesture-and-matched-background.md)へ。制作システムの方針は継続。初回作品の部屋・台詞は演出案）
- 日付: 2026-10-23
- 決定者: ユーザー（全身アニメーション方式と初回動画の制作依頼）、エージェント（実装方式）

## 背景

現在の配信画面ではなく、auto_movieを参考に全身アニメーションを収録できるシステムと最初のショート動画を求められた。しゃがむなどの動作にはその動き・画角専用の画像を作り、背景も場面に必要な画像を作って人物が空間内にいるようにする指示がある。

## 決定内容

- 事前制作動画の主経路を `tools/shorts/render.py` と台本JSONによるオフライン合成へ変更する。既存収録室は補助用として保持する。
- auto_movieの台本・画像素材・音声の分離、音声実尺による字幕同期、素材ハッシュと制作manifestの考え方を参考にする。他プロジェクトの人物・世界観・運用規則は持ち込まない。
- 必要な動作・画角に合わせて既存デザインver1を参照した画像を生成し、実透過を保持して保存する。立ち・しゃがみ・お辞儀・会話表情を別素材にする。
- 生成した室内背景に人物を接地させ、影、前景による遮蔽、足元基準の位置と倍率、背景と人物が一緒に動くカメラで空間を表現する。
- 採用済みVOICEVOX設定を読み込み、小さな震えの後処理を再現する。台詞ごとに生成した音声実尺へ字幕と場面を同期し、H.264/AACの縦型MP4を出力する。
- 初回作品「隠れてご挨拶」を制作する。全身映像を確認できる初回サンプルであり、段階公開の初日用素材と公開スケジュールを確定するものではない。具体的な台詞・部屋・投稿時期は恒久設定に反映しない。

## 理由

単一の立ち絵の縮小ではしゃがみの姿勢や奥行きを表現できない。専用画像を空間レイヤーで合成し、音声実尺へ同期させると、配信画面の手動録画に依存せず再生成と確認ができる。

## 影響

- 初回ショートの最終画角は[ADR 0019](0019-close-opening-and-bust-framing.md)で寄り・バストアップへ部分置換。全身素材を使う制作方式は継続する。

- 納品前の視覚検証は後継の[ADR 0018](0018-mandatory-visual-continuity-review.md)で必須化。既存の技術検査だけでは完成扱いにしない。

- ADR 0003の事前制作動画の主収録経路を本ADRで部分置換する。配信用収録室そのものは存続する。
- ADR 0014の収録室用ビジュアル機能は継続するが、初回ショートでは専用の室内背景と自動字幕を用いる。
- ADR 0004の目標経路を具体化し、ADR 0007の声を使用する。ADR 0013の段階公開方針は変更しない。初回全身映像の公開は本作業に含まない。
- 実装は専用ポーズを用いる2D画像アニメーション。関節リグ・連続する歩行・3D化は実装していない。
- 画像生成は対話で実施する。レンダラーからの自動画像生成や自動投稿は含まない。
- 初回環境ではauto_movie同梱FFmpegが起動時に停止したため、作業フォルダー内に独立したFFmpegを取得する。環境依存パスは差し替え可能にする。
