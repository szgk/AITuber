# ADR 0019: 冒頭を机越しの寄り、その後をバストアップにする

- 状態: 採用（画角の指定と修正版v3の制作）
- 日付: 2026-10-23
- 決定者: ユーザー

## 背景

ユーザーから添付画像とともに「あともう少しアップで写っていい」「最初はこれぐらいズームしてて、その後はバストアップで写るぐらい」と指定された。従来は全身が画面内に収まる遠い構図だった。ADR 0018の視覚レビューでは机の下の遮蔽と場面切替の二重像が不合格になっている。

## 決定内容

- 最初の2場面は添付画像程度の机越しの寄りにする。舞台全体に対するカメラ倍率は2.25、左の机と頭付近を中心にする。
- 自己紹介以降の3場面は顔・肩・胸元が中心になるバストアップにする。カメラ倍率3.1、人物の上半身を注視する。全身を必ず画面に入れる運用は本作品では置換する。
- 全身素材・動作用画像を使う制作システムは継続し、人物と背景を合わせてカメラを適用する。既存の作画と顔を隠す専用ポーズは維持する。
- 机の奥のしゃがみ位置・縮尺を奥の床面に合わせ、身体と靴が机の幕板の後ろに収まるよう再配置する。床を矩形で貼り戻すマスクを除き、机の輪郭へ前景を修正する。ズームだけで以前の不具合を隠すことはしない。
- 机上のペン立て・ペンも個別の前景として合成し、頭を左へ配置して顔との重なりを調整する。ペン立てが顔で途中から切れたり、ペンが頭から生えたように見えないことを確認する。
- カメラ位置の違う場面同士はカットで切り替え、部屋全体のディゾルブによる二重像を除く。ポーズ列は短い専用ポーズの切替とし、腕の二重像が出るディゾルブは使わない。
- 旧v2とその不合格記録を保存し、v3を別フォルダーへ出力する。最終動画に対しADR 0018のレビューを実施する。

## 理由

顔の表情と手の仕草を読み取りやすくし、ユーザーが指定した距離感で見せる。全身システムの使用と最終的な画角を分け、カメラ位置変更に伴う合成の矛盾も解消するため。

## 影響

- 後継の[ADR 0021](0021-mouth-only-sync-foreground-and-reading.md)で口パク・ライトの遮蔽・読みを修正する。画角は継続。v3の検証後にこれらの指摘があり、以前の合格を今回の修正済みの根拠にしない。

- ADR 0015の初回全身フレーミングとADR 0016のv2配置を部分置換する。全身用素材・音声・字幕・人物設定は継続する。
- ADR 0018の必須レビューは継続。v2の不合格履歴は消さず、v3の結果は新しい動画ハッシュと結び付ける。
- 現行台本は `projects/short-001/storyboard.json`、v2の台本は `storyboard-v2.json`、出力は `outputs/shorts/short-001-v3/`。
- 拡大画像には既存の生成素材を使う。新規画像を生成したとは扱わない。
- 画角・位置だけの変更では台詞の音声を再利用できるよう、音声照合を台詞・余韻・声の設定に限定し、実尺を保ったまま最新の配置をタイムラインへ反映する。

## 検証結果

- v3最終MP4（23.23秒・1080×1920・30fps）の実フレーム47点、家具境界の拡大、原寸2点、場面・ポーズ境界の各5連続フレームを確認した。
- 冒頭の机越しの寄りと後半のバストアップを確認。足元・床の矩形切断、机上小物との重なり、場面とポーズの二重像は解消し、視覚レビュー6項目と技術検証が合格した。
- 動画と証拠のハッシュをレビュー記録に保存。動きは専用ポーズの段階的切替であり、連続した関節アニメーションではない。
