# ADR 0019: デビュー14日前からの投稿原稿と静止画を保存する

- 状態: 採用（制作・保存の依頼）。日割り・原稿・静止画の具体案は提案。
- 日付: 2026-10-23
- 決定者: ユーザー

## 背景

ユーザーから「二週間前からのツイート内容の文書と画像を作成して保存する」と依頼された。ADR 0008・0013と既存計画を踏まえ、「二週間前」はデビュー14日前と解釈した。

## 決定内容

- D−14から当日まで15投稿分の日本語原稿、投稿ごとのTXT、1200×1200のPNG、代替テキスト付きJSONを `outputs/debut-posts/` に保存する。
- 既存デザインと採用ロゴを使うグラフィックカードとし、頭頂部、口元、片目、顔、上半身、全身へ公開範囲を広げる。
- 静止画として成立するよう、D−12は手の挨拶から挨拶の練習に変更し、動作に依存する文面を調整する。変更は具体案であり、段階公開や動画方針の置換ではない。
- 新たな人物設定は追加しない。デビュー日・時刻・URLは未確定として保持する。

## 理由

既存の企画文だけでなく、投稿文と添付用実画像を組にして確認できる形にするため。

## 影響・未解決点

- 後継: [ADR 0020](0020-face-closeup-expression-roughs.md)により、顔のアップ・豊かな表情の画像ラフを先行し、その後に声付き短編動画を作る。旧カード構図は部分置換し、ファイルは履歴として保持する。

- 1日1投稿の日割りは引き続き提案。公開前にデビュー日・公開時刻・公開先URLを確定する。
- 今回の依頼対象は文書と画像。D−14の頭の動き、D−7以降のカウントダウン動画・音声は未制作であり、静止画で完了したとは扱わない。
- 外部投稿は実施していない。元の企画文書は履歴として保持する。
- ADR 0018の動画v2の不合格は本制作と別であり、解消していない。
