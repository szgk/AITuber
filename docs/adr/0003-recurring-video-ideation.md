# ADR 0003 動画企画を定期的に自動作成する

- 状態: 部分置換（定期実行はADR 0027で一時停止。企画形式は維持）
- 日付: 2026-10-23

後継: [ADR 0027](0027-pause-video-ideation.md)。2026-10-25のユーザー指示により自動化 `automation-3` は停止済み。再開指示があるまで定期生成しない。

## 背景

ユーザーから「さらに動画案を自動で作っていく」と指示があった。既存設定と企画を引き継ぎ、重複を避けながら動画の候補を蓄積する。

## 決定と理由

このスレッドの定期タスクでショート3案とロング1案を毎回作成する。頻度と件数は運用の初期値としてエージェントが設定した毎日午前9時（日本時間）とし、ユーザーの指定に応じて変更する。登録済みの自動化IDは `automation-3`。

各回は既存プロフィール、関連ADR、既存企画を読み、タイトルだけでなく題材・展開・結末の重複を確認する。案は `docs/video-ideas/` に日付と必要に応じて連番を付けて保存し、一覧を更新する。タイトル、冒頭、展開、結末、必要素材、設定の根拠を含める。ショート1案を台本化し、ロングには時間配分と切り出し候補を付け、制作判断に使える粒度を保つ。

## 影響

生成結果は提案であり、公開済みの出来事や確定設定にはしない。新しい設定判断はADR 0002に従い、未採用なら提案として記録する。同じ提案のADRを繰り返し作らない。動画生成・公開や実行用人格への反映は本運用に含めない。

定期タスクの登録は完了している。将来の実行結果は各回の完了報告で確認する。
