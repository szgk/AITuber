# ADR 0016: お辞儀を使わず顔を隠す仕草と背景の作画を合わせる

- 状態: 採用（お辞儀を除く演出と背景作画の統一。髪を直すという解釈は制作上の仮定）
- 日付: 2026-10-23
- 決定者: ユーザー

## 背景

初回ショートに対し、ユーザーから「お辞儀とかはしない」「手で上お直す動きで顔を隠したりする」「背景画像もキャラクターと同じような作画にする」と修正指示があった。ADR 0015の初回作品ではお辞儀と、人物よりも描き込みの多い背景を使っていた。

## 決定内容

- 初回ショートからお辞儀を除き、上体を起こしたまま手と髪で顔を隠す一連の仕草へ変更する。
- 「上お直す」は「髪を直す」と暫定解釈する。意味の確認はユーザーへ提示済みで、返答により変更可能。ユーザーが明確に採用した語義とは扱わない。
- 手を髪へ上げる、前髪と手で顔が隠れる、耳元へ髪をよける専用の全身画像を作る。足元と全身倍率を揃え、場面内の時系列で切り替える。
- 背景はキャラクター画像を作画の参照に使い、太い黒線、簡単な影、少ない細部、落ち着いた色で描き直す。元の描き込みの多い室内画像は現行出力で使用しない。
- 修正版の台詞は「緊張すると、つい、顔を隠したくて……。」とし、仕草と字幕・音声を一致させる。これは作品内の台詞であり人物プロフィールの追加ではない。
- 旧素材と初回動画は履歴として残し、修正版の素材は `assets/shorts/001/v2/`、動画は `outputs/shorts/short-001-v2/` に保存する。

## 理由

ユーザーの指定した内向的な仕草を具体的な動作として表すため。人物と背景の線・塗り・描き込みを合わせることで同じ作品の空間として見せる。

## 影響

- v3の画角と人物配置は[ADR 0019](0019-close-opening-and-bust-framing.md)へ移行。顔を隠す仕草と背景の作画方針は継続する。

- 足元・遮蔽の指摘とレビュー義務化は[ADR 0018](0018-mandatory-visual-continuity-review.md)に記録。修正版v2は視覚不合格・未修正であり、本ADRへの対応済みだけで完成としない。

- ADR 0015の「お辞儀を別素材にする」と初回背景の選択を部分置換する。台本・専用画像・音声実尺・空間レイヤーによる制作方式は継続する。
- 旧お辞儀画像は履歴用で、現行台本の素材参照と場面の両方から外す。
- 場面の `poseSequence` に相対時刻と専用ポーズを列挙し、接地位置を保って短いディゾルブで接続できる。3D関節リグや連続した手指の物理演算ではない。
- 前景マスクを新背景の机の実位置へ合わせ直す。
