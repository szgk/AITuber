# ADR 0007: 京子の声に比較サンプル⑥を採用する

- 状態: 採用
- 日付: 2026-10-23
- 決定者: ユーザー（6種類の比較への回答「6」）

## 背景

ADR 0006で作成した音声比較に対し、ユーザーが⑥を選択した。気弱で少し震える声というADR 0005の方針を、具体的な音声設定として確定する。

## 決定内容

京子の動画用音声は、VOICEVOX「ナースロボ＿タイプＴ・ノーマル」に小さな震えを加えた⑥を採用する。比較に使用したVOICEVOXは0.25.2、話者UUIDは `882a636f-3bac-431a-966d-c5e6bba9f949`、スタイルIDは47。エンジン更新時にはUUIDとスタイル名も確認する。

合成設定は話速0.88、抑揚0.80、音量0.95、前無音0.22秒、後無音0.32秒、24kHzモノラル。後処理で音高に深さ0.002・4.6Hzの揺れ（位相に深さ0.3・0.7Hzの変調）、音量に最大0.055・4.1Hzの減衰を加える。実装済みの比較生成スクリプトと同じ設定を `config/kyoko-voice.json` に保存する。

## 理由

ユーザーが比較サンプル⑥の声を選択したため。声質と小さな震えの程度を今後の動画制作の基準にする。

## 影響

- ADR 0006の「声・本番エンジンは未採用」という未決定部分を本ADRで解決する。比較経緯は保存する。
- クレジットは `VOICEVOX:ナースロボ＿タイプＴ` とする。前回確認した利用条件はADR 0006を参照する。
- 声の採用と収録室への音声生成統合は別であり、今回の作業は採用記録・設定保存までとする。設定ファイルを収録室が自動的に読み込む実装はまだない。
- 比較音声の台詞固有のアクセントクエリは、新しい台詞にそのまま流用せず、台詞ごとに生成する。
