# ADR 0021: 口だけを音素同期しライトの前後関係と読みを修正する

- 状態: 採用（指摘に対する修正方針とv4制作）
- 日付: 2026-10-23
- 決定者: ユーザー

## 背景

初回ショートv3に対し以下の指摘があった。

- 「口を開けたり占めたりするときになぜか目のハイライトも変わってしまっている」
- 「音声が流れているのに口が閉じたままになっている」
- 「机の上のライトの支柱の前に紙が出てしまっているが、空間的にはライトの支柱の後ろに髪の毛があるはず（ライトは机の上にあり、キャラは机の後ろにいるので）」
- 「読み上げの音声が『お話し』を読むとき『おはなしし』と呼んでしまっている」

「紙」は後続の説明から髪のこととして対応する。従来の口パクは顔差分の合成範囲に目元を含み、立ち姿以外では動かず、固定周期の強制閉口と音量閾値にも依存していた。前景マスクには机とペン立てしかなく、ライトの細い支柱が含まれていなかった。

## 決定内容

- 顔差分の合成を廃止し、既存の口の範囲だけを描画する。目・ハイライト・頬・髪は口パクで変更しない。立ち姿・髪へ手を伸ばす姿勢・耳元へ髪をよける姿勢のそれぞれで口元を指定する。
- VOICEVOXのクエリに含まれる子音・母音・休止の長さをWAV実尺へ正規化し、タイムラインに音素ごとの口の開き具合を保存する。固定周期で口を閉じる処理と大きな音量閾値による判定は廃止する。
- 手と前髪で口が物理的に隠れる姿勢、および机で口が隠れる冒頭では、口を手や机の上に描かない。口が見える姿勢と遮蔽される姿勢を区別する。
- ライトの原画から支柱・シェード・台座の輪郭を抽出し、机上の前景として人物より後に合成する。髪を支柱より手前へ描かない。
- 字幕は「少しずつ、お話しできたら、うれしいです。」を保持し、読み上げ入力を別フィールド `speechText` の「少しずつ、おはなしできたら、うれしいです。」へ変更する。読み上げ文字列を音声キャッシュと再利用照合のキーにも含める。
- 音声クエリのモーラ列で「オハナシデキタラ」であり「オハナシシ」ではないことを検査し、旧音声を誤って再利用しない。
- v3の動画と台本を保存し、v4を別フォルダーに出力して視覚レビューを実施する。

## 理由

口以外の変化を合成範囲の設計で防ぎ、静かな声でも口パクが止まらないよう発話の時間情報へ同期させる。机上の細い物体も人物と同じ前後関係で扱う。表記と読みを分け、日本語の自動解析による誤読を固定する。

## 影響

- 後継の[ADR 0022](0022-smooth-mouth-and-pose-landmarks.md)で輪郭のギザつきと姿勢ごとの位置ずれを修正する。音素同期・目元の不変性・ライトと髪の前後関係・読みの修正は継続する。

- ADR 0019の画角・字幕・姿勢の方針は継続し、口パク・ライトの遮蔽・読み上げだけを本ADRで置換する。
- 顔差分用のspeaking画像は履歴として残すが、現行台本と描画では使わない。口元は既存イラスト上の限定領域をコードで描画する。
- 音声同期はVOICEVOXが出力した長さに基づく2D口パクであり、音声認識による強制アラインメントではない。
- 回帰検査で口以外の画素が不変であること、可視ポーズすべての口が動くこと、無音時は閉じることを確認する。視覚確認は最終MP4の口元・目元・ライトの境界でも行う。
- 過去のv3への合格判定で今回の指摘が解消していたとは扱わない。旧記録を残し、v4の対象ハッシュと証拠を分ける。

## 検証結果

- v4は23.03秒・1080×1920・30fps。実動画の47フレーム、拡大画像、口元と目元の7連続フレーム、ライト境界の原寸クロップを確認し、視覚・技術検証が合格した。
- 3つの可視ポーズについて、口を開けても口の指定領域外の全画素が不変であることを回帰テストで確認。音素と無音区間のテストも合格した。
- 実WAVの有音フレームと開口指定の時間対応は各場面88.5〜100%。遮蔽された口は表示しない。
- 読みは合成クエリのモーラ列で「スコシズツオハナシデキタラウレシイデス」を確認。人による聴感の試聴済みという評価ではない。
