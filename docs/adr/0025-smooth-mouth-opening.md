# ADR 0025: 口の開閉を時間と輪郭の両方で滑らかにつなぐ

- 状態: 採用（ユーザーの要望と実装）。実動画の品質はレビューで管理。
- 日付: 2026-10-24
- 決定者: ユーザー

## 背景

ユーザーから「口の開閉は滑らかにできるか」と要望された。告知動画では音素またはテスト用の区間が切り替わるたびに開口量が段階的に変化し、さらに開口量0.05を境に閉じ口の線と開口楕円を切り替えていた。

## 決定内容

- 告知動画の音素タイムラインの時刻を保持し、開口量の間を5次補間で連続的につなぐ。切り替わり前後の変化量が急に跳ねないようにする。
- 各音素の目標開口量を保持する時間を設け、前後最大55msを移行に使う。短い音素では音素長の35%までに制限する。
- 休止・無音区間は全区間で閉じる。発声開始前に口を先行して開けたり、無音へ開口を長く持ち越したりしない。
- 閉じ口と開口の描画を別図形の切替にせず、上下の輪郭を同じパラメーターで変形する。閉じた線から細い開口、大きな開口へ連続的につなぐ。
- 原画ごとの口角軸、顔と同じ変形、目元の独立性、前回の手パーツ単位の動きを継続する。09の閉じ口は緊張した波形を保持する。
- 対象は告知用動画の06〜15。口が画面に出ない01〜05は元動画を維持する。他作品の口描画や音声は本作業では変更しない。

## 理由

輪郭を高解像度にするだけでは時間的な飛びを除けないため。時間上の補間と図形上の連続性を両方満たす。

## 影響・対応状況

- [告知動画のADR 0022](0022-debut-video-character-animation.md)の段階的な口開閉を部分置換する。[手パーツのADR 0024](0024-rigid-hand-part-animation.md)は継続する。
- 旧版を保存し、修正版は `outputs/debut-motion-preview-v3/` へ別出力する。
- 無音のテスト用開閉で見た目を確認する。声付き本編は未完成であり、今回の確認を実音声同期の検証済みとは扱わない。
- 開口量の連続性・範囲・無音区間・音素時刻と目標値の検査、口の傾きと目元不変性、手の剛体変換の検査を行う。実動画の口元の連続拡大フレームを確認する。
