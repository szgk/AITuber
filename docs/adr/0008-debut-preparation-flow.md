# ADR 0008: デビューまでの準備と告知の流れ

- 状態: 採用（ユーザー指定の準備・告知方針。制作・投稿は未実施）
- 日付: 2026-10-23
- 決定者: ユーザー

## 背景

ユーザーから、ロゴ制作、デビュー約2週間前からのツイート、1週間前からのカウントダウン動画、自己紹介ショート動画、動画の背景・演出の制作をデビューまでのフローとして指定された。

## 決定内容

- Vtuberのロゴを調べ、その調査を踏まえてロゴを作成する。
- デビュー約2週間前からツイートを始める。内容はデビュー前のカウントダウンや短文紹介とする。
- デビュー1週間前からカウントダウン動画を公開する。
- 自己紹介ショート動画を制作する。
- 動画の背景と演出を制作する。

具体的な準備順序と未決事項は[デビュー準備フロー](../debut-preparation-flow.md)で管理する。デビュー日、投稿頻度、自己紹介動画の公開日は未決定。

## 理由

ユーザーが指定した準備項目と告知の開始時期を、制作・公開計画の基準として残すため。

## 影響

- デビュー日が決まり次第、相対日程を実際の日付へ展開する。
- 告知用の素材は公開開始に間に合うように準備する。具体的な制作順序は作業上の提案として区別する。
- 動画制作はADR 0004の事前制作方針、音声はADR 0007の採用設定に従う。既存の決定は置換しない。
- 本ADRは制作・告知方針の記録であり、外部への投稿や公開の実施記録ではない。
