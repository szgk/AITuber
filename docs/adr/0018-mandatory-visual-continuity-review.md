# ADR 0018: 空間・身体・動きの矛盾を必ず視覚レビューする

- 状態: 採用（レビューの義務化と実装。現行v2動画の問題は未修正）
- 日付: 2026-10-23
- 決定者: ユーザー

## 背景

ユーザーから画像を添えて「足と床の見え方がおかしい」「こういう矛盾やおかしい点をレビューするskillを作って必ずレビューするようにしてください」と指摘された。机の奥からのぞく人物の脚・靴と、机・椅子・床の前後関係が不自然に見える。以前の縮小画像中心の確認とデコード・音量検査では問題を見落とした。

## 決定内容

- `.agents/skills/visual-continuity-review/` にスキル原本を作り、人物・背景の合成画像や動画を制作・修正した場合の納品前に必ず適用する。
- 接地・床、遮蔽・前後関係、身体・姿勢、時間・カメラ、作画・光、指摘・画面の6項目を実出力で確認する。技術検査だけで視覚合格にしない。
- 最終MP4の各場面の冒頭・中間・終端、ポーズ切替前後、カメラ移動の大きい箇所を抽出し、足元・家具境界を拡大する。証拠生成はレビューの代わりにはならない。
- 動画と証拠画像のSHA-256、実際に見た証拠、項目別判定、具体的な所見と未解消事項を `visual-review.json` に記録する。未レビュー・不合格・証拠不足・別動画への合格は検証を失敗させる。
- 書き出し時はレビュー未完了として通知し、全項目合格まで完成・確認済みとして納品しない。修正後は実際の再出力を再レビューする。
- AGENTS.mdと各指示ファイル、毎セッションの指摘引き継ぎ一覧にこの義務を記す。

## 理由

マスクや足元座標が計算上成立していても絵として前後関係や身体が成立するとは限らない。実出力の拡大確認と証拠保存を必須にし、コーデック・音量の正常と空間の正常を混同しないため。

## 影響

- 後続のv3では[ADR 0019](0019-close-opening-and-bust-framing.md)に従って画角・奥行き・遮蔽・二重像を修正する。v2の不合格記録とレビュー義務は継続する。

- ADR 0015・0016の制作方式を継続し、納品前検証を本ADRで補強する。指摘はADR 0017に従って永続化する。
- 現行 `short-001-v2` は視覚不合格として記録する。以前の「確認済み」は引き継がない。今回の依頼はスキル作成と必須化であり、動画を修正したとは扱わない。
- 自動化するのは証拠抽出と記録・ハッシュ・判定の検査。画像の意味を自動判定できるとは主張しない。
- レンダラー変更後も既存動画をレビューできるよう、出力時とのハッシュ差異は報告する。過去のmanifestを書き換えない。
