# ADR 0020: 告知は顔のアップと豊かな表情を画像ラフで先に確認する

- 状態: 採用（画角・表情と制作順序）。個別ラフの表情・構図は提案。
- 日付: 2026-10-23
- 決定者: ユーザー

## 背景

告知静止画に対し「もっと顔のアップで作る」「あと表情はもっと豊かにする」「まずは画像でラフを出して、あとから声付きの短い動画にします」と指示された。

続けて「顔を中心に見せることはADRに残す」と明示されたため、今回のラフだけでなく、その後の告知画像・声付き短編動画に引き継ぐ構図方針として記録する。

## 決定内容

- 涙の作画への追加指摘原文: 「涙だけ急にリアル作画になってる」「汗と同じような白い漫画みたいな作画でいち」。末尾は未完のため補完せず、明確な部分を「14の涙を汗と同じ白ベタ・黒輪郭の漫画表現に統一する」と解釈して対応する。透明感・水色・光沢・写実的なハイライトを使わない。
- 追加指示: 「09はぐるぐる目」「14もぐるぐるめで目に涙を浮かべる」「全体的に頬染めは弱くする」。告知ラフ09の両目を渦巻きにし、14は両目の渦巻きと目元にたまる涙を描く。頬染めは全コマで弱める。この3点はユーザー指定として採用し、他の個別表情案と区別する。
- **告知画像と、その後に制作する声付きの短い動画は、顔を中心に見せる。** 表情が読み取れる大きさと配置を基本にし、背景・ロゴ・全身より顔の見やすさを優先する。
- 顔を見せる段階からは、顔と髪が画面の大部分を占める寄りの構図にする。
- 照れ、緊張、好きな物を話す喜び、安堵、考え込みなど、眉・目・口・頬と手の仕草で描き分ける。
- まず画像ラフで構図・表情を提示する。その後に声付きの短い動画を制作する。今回動画を完成したとは扱わない。
- 段階公開の序盤は頭頂部、口元、片目を見せる方針を維持する。
- 既存デザインを参照し、imagegen組み込みツールで15コマのラフを制作し `outputs/debut-posts/rough-v2/` に保存する。

## 理由

投稿の小さな表示でも感情を読み取れるようにし、動画制作前に画面の方向性を確認できるようにするため。

## 影響・対応状況

- 後継: [ADR 0022](0022-debut-video-character-animation.md)で各ラフの構図・表情を動画制作の基準として採用。涙を小さな普通の楕円に変更し、頭・顔・目・手・右上の跳ね毛を動かす声付き動画の制作へ進む。下記の未採用・未制作は当時の状況として保持する。
- 涙の作画を修正したv4を `outputs/debut-posts/rough-v4/` に保存。v3の水色の涙は後継v4に置換し、旧ファイルは履歴として保持する。
- 追加指示を反映したv3を `outputs/debut-posts/rough-v3/` に別保存する。v2は履歴として保持する。動画は引き続き未制作。
- [告知素材のADR 0019](0019-debut-post-assets.md)の余白が多いカード構図を後継ラフへ部分置換。旧版は保存する。初回ショート用の同番号ADRとは別件。
- 全身公開を前日に行う旧具体案より、今回の顔アップを優先する。全身公開日を確定したとは扱わない。
- ラフは15日分の構図・表情案。単体の完成投稿画像・音声・動画用の分離素材・口パク差分は未制作。
- デビュー日・時刻・URL、ラフの採否は未確定。表情案を性格設定の追加として扱わない。
