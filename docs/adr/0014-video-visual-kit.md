# ADR 0014: 動画の背景・字幕・演出を収録室に用意する

- 状態: 採用（制作と実装。ビジュアルの正式採用は未決定）
- 日付: 2026-10-23
- 決定者: ユーザー（制作依頼）、エージェント（試作の実装判断）

## 背景

ユーザーからデビュー準備フローの背景・字幕・演出の制作を依頼された。既存収録室を使い、告知・自己紹介に繰り返し利用できる素材を用意する。

## 決定内容

- 淡い月あかり・紺色の夜・あたたかな紙色の背景、紺・白の角丸字幕を追加する。
- 採用ロゴ、見出し、残日数と、0.7秒の登場・退場フェードを追加する。
- 正方形1080×1080を追加し、縦・横と合わせ背景PNG9枚を保存する。
- 個別の色とレイアウトは試作であり、ユーザーによる正式採用とは区別する。

## 理由

既存のCanvas録画へそのまま反映でき、背景PNGは別の編集ソフトでも再利用できる。追加依存なしで実際の映像を確認できる。

## 影響

- 字幕送りと退場の開始は手動。音声同期、部分公開マスク、BGMは未実装。
- サーバーは採用ロゴの1ファイルを追加で公開する。
- ADR 0003、0004、0008、0013は継続。世界観・人物設定は変更しない。
