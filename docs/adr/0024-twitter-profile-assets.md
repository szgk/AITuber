# ADR 0024: Twitterアイコンをぐるぐる目にしヘッダーにロゴを使う

- 状態: 採用（ユーザー指定）。具体的な画像デザインは確認待ち。
- 日付: 2026-10-23

## 背景

ユーザーから「ツイッター用のアイコンとヘッダー画像の作成　ヘッダーはロゴを使う」、続けて「アイコン画像はぐるぐる目」と指定された。

## 決定内容

アイコンは京子の顔アップ、両目をぐるぐる目とする。ヘッダーはADR 0012の採用ロゴを参照して制作する。組み込みimagegenを使い、投稿用PNGは400×400と1500×500で保存する。

## 理由

ユーザーが指定した表情とブランド素材をプロフィール画像へ反映するため。

## 影響・対応・未解決点

outputs/twitter-profile-v1/ に生成原寸・投稿用画像・円形プレビュー・視覚レビューを保存した。ヘッダーはロゴを参照した生成であり、元PNGの画素の完全一致は保証しない。今回の具体案の最終採用は未確定。外部公開は実施していない。足・床・家具は画面に存在せずレビュー対象外。
