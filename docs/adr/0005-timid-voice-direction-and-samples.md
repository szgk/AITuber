# ADR 0005: 気弱さと小さな震えを持つ声の方向性

- 状態: 採用（声の方向性のみ。サンプル・音声エンジンは未採用）
- 日付: 2026-10-23
- 決定者: ユーザー

## 背景

動画制作の合成音声について、ユーザーから「声は気弱で少し震えてる感じにしたい」「サンプルをいくつか出せるか」と依頼された。

## 決定内容

声の方向性は気弱で、小さな震えを含むものとする。比較のため、同じ自己紹介を使い、控えめ・少し緊張・震えを強めた比較用の3種類を試作する。どの候補を使用するかは未決定とする。

この端末にインストール済みのMicrosoft Harukaをベースに、速度と小さな音高・音量の揺れを後処理で変える。外部サービスへの送信、追加モデルのダウンロードは行わない。これは方向性の比較用であり、感情演技を備えた本番音声として採用する判断ではない。

## 理由

同じ台詞・同じベース音声で震えの程度を比較できる。既存のローカル環境で試作し、声の選定を先に進められる。

## 影響

- サンプルは `outputs/voice-samples/` に生成する。音声ファイルは既存のgitignore対象であり、再生成スクリプトを保持する。
- 機械的な揺れの加工と、自然な気弱さの演技は異なる。試作の聞こえ方をもとに本番の声と合成エンジンを選ぶ。
- 公開動画での利用条件確認と本番エンジンの採用は別途行う。
- 自動音声生成の収録室への統合は本作業には含まない。
