# ADR 0022: 口の輪郭を滑らかにし元画像の口を基準に位置を合わせる

- 状態: 採用（口元の指摘に対する修正とv5制作）
- 日付: 2026-10-23
- 決定者: ユーザー（品質・位置の指摘）、エージェント（具体的な修正方式）

## 背景

ユーザーから「口がガビガビになってないか」「後口の位置がシーンによってズレていないか？」と指摘された。v4の実MP4を姿勢ごとに拡大して確認すると、開口輪郭に階段状の段差があり、耳元へ手を添える姿勢では元の閉じ口に対して開口位置が右上へずれていた。

従来は口の楕円を低い解像度の全身合成面へ直接描画してからカメラ拡大していた。また、口の中心を姿勢ごとに概算していた。特にhairTuckでは原画上で約10画素右、約5画素上のずれがあり、拡大後には約20画素以上の違いになる。

## 決定内容

- 口の限定領域だけを8倍の解像度で描画し、Lanczos縮小でアンチエイリアスを付ける。顔全体をぼかして輪郭の粗さを隠さない。
- 口の位置は、各姿勢の元画像にある閉じ口の輪郭矩形を実測し、その中心に合わせる。頭や目の位置が違う姿勢に同じ概算の中心を流用しない。
- `closedMouthBox` と `landmarkSourceSize` を台本に保存する。立ち姿・髪に手を伸ばす姿勢・耳元へ手を添える姿勢それぞれで、元の口と開口中心の一致を検査する。
- 目・ハイライト・頬・髪を変えないADR 0021の制約、音素同期、読みの修正、前景のライトは継続する。
- v4とそのレビュー履歴を残し、v5を別フォルダーへ出力して実動画の口元と姿勢切替を再レビューする。音声は変更しない。

## 理由

拡大時の口の線だけが画素の段差として目立つことと、開閉によって口の位置が跳ねることを防ぐ。顔の別パーツを巻き込まず、各原画の顔に対する正しい位置へ口を置くため。

## 影響

- 口の向きは後継の[ADR 0023](0023-mouth-axis-follows-face-tilt.md)で顔の傾きへ合わせる。中心位置と輪郭の品質の方針は継続する。

- ADR 0021の口描画の解像度と位置決めを本ADRで部分置換する。v4の以前の合格は、この2点を解消していたという根拠にしない。
- 口の元画像ランドマーク、画素変更の範囲、無音・音素同期の回帰検査を必須にする。
- 新規のキャラクター画像は生成しない。既存画像上の口の限定領域を描画する処理の改善である。
- 台本v4は `storyboard-v4.json`、新出力は `outputs/shorts/short-001-v5/` に保存する。

## 検証結果

- v5の実MP4（23.03秒・1080×1920・30fps）から、立ち姿と髪を直す2姿勢の閉口・開口を抽出して比較。階段状の輪郭が滑らかになり、耳元へ手を添える姿勢の口の右上へのずれが解消したことを確認。
- 全47確認フレームと拡大一覧、目元・口元の7連続フレームも確認し、視覚レビューと技術検証が合格した。
- 回帰検査3件（姿勢別の原画上の口位置、口以外の画素不変性、音素・無音の対応）が合格。音声トラックのハッシュはv4と同一。
