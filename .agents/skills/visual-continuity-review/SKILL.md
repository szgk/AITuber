# 映像・画像の空間整合性レビュー

## 入力と証拠

対象の最終画像または書き出された動画、台本・配置情報、ユーザーの指摘を読む。制作途中のCanvasや代表サムネイルだけで最終動画を合格にしない。動画は各場面の冒頭・中間・終端、ポーズ変更の直前直後、カメラ移動の最大位置を確認する。動きの判定には連続フレームを使い、静止画しか見ていない場合は滑らかさを確認済みと書かない。

このリポジトリでは `python tools/shorts/prepare_visual_review.py --output <出力フォルダー>` で実MP4のフレーム・足元拡大・一覧と未レビューの `visual-review.json` を生成できる。別の制作環境では利用可能な抽出手段を使う。

一覧を画像表示ツールで見たうえで、足元・手指・家具境界など疑わしい部分を原寸または拡大して見る。証拠を生成しただけではレビューしたことにならない。対象を見られない場合は未レビューとし、推測で合格にしない。

## 判断項目

- **接地・床**: 左右の靴底は同じ床面に乗っているか。床板の方向、消失方向、床と壁の境界、接地影と人物の奥行きは一致するか。足先が浮く・床に埋まる・机の奥にいるのに足だけ手前に出るなどを探す。
- **遮蔽・前後関係**: 頭から胴体、膝、足まで、一人の身体として家具の同じ側に収まるか。机板・幕板・脚・椅子の脚それぞれの輪郭と重なりを確認する。矩形や粗い多角形マスクが空中の脚を切断していないか。切り抜き境界が床板や身体を不自然に消していないか。
- **身体・姿勢**: 関節の曲がり、手指、腕の接続、しゃがんだ時の重心と膝・靴の位置、人物と家具の縮尺が成立するか。顔が隠れる演出でも、隠れた身体を想定すると矛盾しないか。
- **時間・カメラ**: ポーズ切替で足元、頭身、左右、手の位置が飛ばないか。ディゾルブで余分な腕や二重の顔が長く残らないか。カメラ移動で人物と背景が別々に滑らないか。開始・終了の一枚だけで判断しない。
- **作画・光**: 人物と背景の線幅、塗り、描き込み、光源、影が同じ場面として整合するか。意図したデフォルメと空間の破綻は区別する。
- **指摘・画面**: 有効なADRの禁止事項・要求に沿うか。字幕、画面端、前景が意図せず手足や顔を切らないか。ユーザーが問題視した箇所を必ず再確認する。

## 判定と修正

問題は「時刻または場面・位置・見える症状・成立しない関係・影響・修正案」で記録する。観察と原因仮説を分ける。脚が見えること自体を禁止せず、全身と家具を合わせてその見え方が成立するか判断する。

明らかな接地・遮蔽・身体の矛盾、ユーザー指摘の未解消、必要な証拠の未確認は不合格または未レビューとする。デコード・解像度・音量が正常でも視覚合格にはならない。問題があれば、配置・透視図・素材・前景マスクのどこを直すべきか判断し、修正が依頼範囲に含まれる場合に修正する。靴だけを隠すなど症状を消す修正で別の矛盾を作らない。

修正した場合は再書き出し後の実動画を再レビューする。新しい動画のSHA-256と証拠画像を結び付け、旧動画の合格を流用しない。未解消の問題を残したまま「完成」「確認済み」と報告しない。レビューだけの依頼では修正や再レンダリングを勝手に追加せず、不合格と改善点を報告する。

## 記録

レビュー記録に対象パス・動画SHA-256、実際に見た証拠ファイルとそのSHA-256、項目ごとの合格・不合格・未確認、所見・未解消事項、全体判定を保存する。自動抽出スクリプトは未レビューの雛形のみを作り、合格を自動付与しない。

AITuberでは `visual-review.json` の `inspectedEvidence` に実際に表示して確認した証拠パスを入れ、各 `checks` にその証拠パスと具体的な所見を付ける。問題が一つでも残れば全体を `不合格` にする。ユーザーの指摘と制作ルールの変更は、ルートのAGENTS.mdに従ってADRと引き継ぎ一覧にも記録する。
