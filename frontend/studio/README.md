# 京子の収録室

デザインver1の原画を動かして動画を収録する、HTML/CSS/JavaScriptのローカルアプリです。外部ライブラリのインストールは不要です。描画はCanvas 2D、音声解析・混合はWeb Audio、録画はMediaRecorderを使用します。

制作方針は、動画素材と合成音声を使ったショート・ロング動画の事前制作を優先します。ライブコメントの取得・読み上げ・返信は将来段階です。現在は生成済みの音声ファイルを読み込む方式で、音声の自動生成・動画素材の合成・字幕の自動同期は未実装です。[ADR 0004](../../docs/adr/0004-video-first-production-scope.md)に方針を記録しています。

## 起動

Node.js 18以降とデスクトップ版ChromeまたはEdgeを使用します。リポジトリのルートで実行します。

```powershell
npm run studio
```

[収録室を開く](http://localhost:4173/frontend/studio/)。終了はサーバーのターミナルでCtrl+C。ポートが使用中ならPowerShellで `$env:PORT=4174` を設定してから起動します。HTMLファイルの直接起動ではなくHTTPサーバーを使用してください。サーバーはローカル端末からのみアクセスできます。

## 収録手順

背景3種類、紺・白の角丸字幕、ロゴ・見出し・残日数、登場・退場フェード、正方形サイズとPNG保存を追加しました。[動画素材セット](../../docs/character-design/video-kit/README.md)に素材と使い方があります。従来の帯字幕も選択できます。

1. ショートは縦9:16、ロングは横16:9を選び、画角・背景・大きさを調整します。
2. 合成音声やナレーションの音声ファイルを読み込みます。音量に応じて口が動きます。マイクは不要です。必要な場合だけ「補助設定」から接続できます。ファイル音声はスピーカーからも再生されます。
3. 台本を1行ずつ入力します。「前へ」「次へ」または矢印キーで字幕を送ります。長文は4行まで表示するため、短い字幕に分割してください。
4. 「収録開始」で保存先を指定すると収録を開始します。読み込んだ音声は先頭から再生します。音声ファイルの終了後も録画を継続するので、任意のタイミングで停止します。
5. 「停止・保存」でファイルを確定します。保存先指定に非対応のブラウザは停止後にダウンロードします。

表情は1〜3キーで切替可能です。テキスト入力中はショートカットが無効です。「おしゃべりデモ」は音声なしで口の動きを試す機能です。

録画中は動画サイズと音声ファイルの変更を禁止します。収録中にタブを閉じたり最小化したりせず、表示したまま使用してください。収録は実時間です。WebMが基本であり、投稿先がMP4を必要とする場合は動画編集ソフトで変換してください。

## ロング動画・OBS

Chrome/Edgeの保存先指定では動画を順次ディスクに保存し、録画時間に比例した動画データのメモリ蓄積を避けます。停止するまでファイルは確定しません。空き容量を確保し、まず短いテイクで音声と映像を確認してください。長時間の連続収録の耐久性は端末依存です。

「OBS用の映像表示」を開くと操作UIを除いた画面が表示されます。同一ブラウザの操作画面から設定・表情・字幕・口の動きを同期します。OBSの「ウィンドウキャプチャ」で出力ウィンドウを指定し、音声はOBS側のマイク・デスクトップ音声入力で取得します。OBSの独立したブラウザソースとは同期しません。グリーンバックを選び、OBSのクロマキーフィルターで背景を抜けます。

## 実装の範囲

呼吸・揺れは画像全体の移動・回転、瞬きと口パクは原画に重ねる簡易2D表現です。Live2D Cubismのモデルやリギング、顔追跡、髪の独立した物理演算は含みません。元のデザインを用いる初期収録システムとして実装しています。

## 検証

`node --check frontend/studio/studio.js` と `node --check frontend/studio/server.mjs` で構文を確認できます。`smoke-test.cjs` はPlaywrightとインストール済みEdgeを使い、起動済みサーバーに対して擬似マイク・録画・一時停止・保存・画角・出力同期を検証します。`PLAYWRIGHT_PATH` でPlaywrightのパッケージパスを指定できます。実マイクの音質と長時間の連続収録は別途端末上で確認してください。

技術判断は[ADR 0003](../../docs/adr/0003-browser-avatar-recording-studio.md)を参照してください。
