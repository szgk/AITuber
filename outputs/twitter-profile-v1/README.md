組み込みimagegenで制作。ヘッダーのロゴは採用PNGを参照した生成画像であり、原本の画素そのものを貼り付けたものではない。デザイン案の最終採用はユーザー確認待ち。外部公開は実施していない。

## 最終生成指示の要約

アイコン: 既存アイコンを参照し、両目だけを白地に黒の漫画的な渦巻きへ変更。京子の髪型・右上の跳ね毛・紺の服・淡い背景・白い漫画の汗を維持。円形表示用の余白を確保。
ヘッダー: 採用ロゴを参照し、3:1の横長に紺色ロゴを中央より右へ配置。淡い水色と白、ピンクの花びら、水色の星。左下に余白。人物・追加文言なし。

実ファイル、円形プレビュー、生成原寸を視覚確認。足・床・家具は画面に存在せず対象外。レビューは visual-review.json に保存。
