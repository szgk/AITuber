# 顔アップと表情の画像ラフ v2

制作: imagegen組み込みツール。参照: `docs/character-design/kyoko-design-ver1.png`。生成プロンプトは `prompt.txt` に保存。

声と動きは未制作。日割り・台詞・個別表情は提案。音声制作は採用済みの声を基準に後工程で行う。今回の画像は同一ポーズの連続差分ではないため、そのままコマを順送りして滑らかな動画になるものではない。

足元・床・家具は全コマに存在しない。顔・手・目隠し境界を拡大して確認し、静止画ラフとしての視覚レビューを `visual-review.json` に保存した。
